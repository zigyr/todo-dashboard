# 界面需求说明（给设计师）

> 这是一份「界面长什么样、放什么、什么状态、必须保留什么」的说明。技术细节不用管。

## 0. 产品一句话

把一篇博客，变成下一步行动。

用户粘贴一个网址 → 程序抓取正文 → 用户确认没问题 → 保存到本地文件。之后用户随时回来看，下一步再让 AI 把它拆成可执行的任务。

## 1. 用户和使用场景

- 用户：**一个人用**，不是团队协作工具，没有账号、没有云同步。
- 典型场景：读到一篇好文章 → 贴进来 → 看抓取的标题/正文对不对 → 点保存 → 以后回来看。
- 情绪诉求：界面要**安静、不焦虑**，让人愿意每天打开用一下。

## 2. 整体界面（桌面窗口）

- 窗口默认约 **1180 × 820**，可缩放，最小 **980 × 660**。
- 一屏两栏，左右比例约 **左 1 : 右 2**：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 左：logo + 「Todo Dashboard」；右：「本地存储 · 无账号」 |
| 左栏 | 「最近抓取」列表 + 「本地工作区」信息 |
| 右栏 | 大标题 + 网址输入框 + 抓取预览/结果 |
| 底栏 | 左：版本号；右：快捷键提示 |

## 3. 视觉风格

- **米白 / 暖白为主**，**深绿只做点缀和按钮**，整体干净、留白充足。
- 卡片圆角、极淡阴影，不要浓阴影、不要渐变堆叠、不要花哨装饰。

### 配色（建议值，可微调）

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#F6F3EA` 米白 |
| 卡片 / 输入底 | `#FFFDF8` 暖白 |
| 次级背景 | `#F1EDE2` 浅米灰 |
| 正文文字 | `#1D1C18` 深墨 |
| 次要文字 | `#706D63` 灰褐 |
| 分隔线 | `#E2DDD0` 浅米 |
| 主色（点缀） | `#2E6B4F` 深绿 |
| 按钮深色 | `#1F4B37` 墨绿 |
| 浅绿底 | `#E5EFE7` |
| 错误 | `#A8402C`，浅红底 `#F8E6E1` |

### 字体字号

- 字体：系统默认（Segoe UI / 微软雅黑）。
- 大标题 50、卡片标题 24–25、正文 13–15、辅助信息 11–12。
- 绿色只表达「可行动 / 成功」；灰色只做说明；黑色承载信息。

## 4. 各区块细节

### 4.1 顶栏

- 左：绿色圆角小方块内一个对勾「✓」+ 两行字「Todo Dashboard / READING → ACTION」。
- 右：一个绿色小圆点 + 「本地存储 · 无账号」。

### 4.2 右栏 · 标题区

- 小字眉题「第一步 · 捕获」（绿色）。
- 大标题两行：「把一篇博客，」/「变成下一步。」（第二行绿色）。
- 下面一句说明：「粘贴网址。程序抓取正文并保存到本地；AI 拆解和行动仪表盘在下一步接入。」

### 4.3 右栏 · 网址输入

- 一个圆角输入框（占位文字示例网址）+ 右侧绿色按钮「抓取正文 →」。
- 输入框下方一句小字提示：「支持普通博客文章。付费墙、纯 JS 渲染的页面可能抓不到。」
- 抓取中：按钮变灰禁用，输入框下方出现一条细绿色进度条。

### 4.4 右栏 · 抓取预览卡（核心）

抓取成功后的卡片，从上到下：

1. 眉题「抓取成功 · 先确认再保存」+ 右上角灰色小标签「未保存」。
2. **文章标题**（大字）。
3. 一行元信息：**作者 · 发布日期 · 字数**（缺作者时显示「作者未知」，缺日期时显示抓取时间）。
4. 一段**正文摘要**（左侧绿色竖线 + 浅米底，约 280 字）。
5. 「查看正文」（可展开，展开后是可滚动的全文）。
6. 底部三个动作：**保存到本地**（绿）· **放弃**（描边）· **打开原文 ↗**（文字链接，靠右）。

### 4.5 右栏 · 已保存卡

- 左侧绿色圆底一个对勾「✓」。
- 中间：眉题「已保存到本地」+ 文章标题 + 两个文件路径（`.md` 和 `.json`，小字、可换行）。
- 右侧按钮「再抓一篇」。

### 4.6 左栏 · 最近抓取

- 标题「最近抓取」+ 右上「刷新」。
- 每条记录：标题（加粗）+ 一行小字「域名 · 字数」+ 时间。点击可在浏览器打开原文。
- 为空时显示「还没有记录。抓取第一篇文章后，会出现在这里。」

### 4.7 左栏 · 本地工作区（重点细化）

- 顶部：文件夹图标 + 标题「本地工作区」。
- 路径：一个浅米底小框，显示本地文件夹路径，右侧「打开 ↗」可打开该文件夹。
- 三个小信息块（并列）：**文章数** · **文件格式（JSON + Markdown）** · **最近抓取时间**。
- 一句说明：「数据就是文件，可以用记事本或 Obsidian 打开，随时带走。」

### 4.8 底栏

- 左「Todo Dashboard · 0.1.0」，右「Ctrl + Enter 抓取 · Esc 重置」。

## 5. 各种状态

| 状态 | 界面表现 |
| --- | --- |
| 空状态 | 右栏显示引导语「粘贴网址，先看看抓到了什么」，左栏「还没有记录」 |
| 抓取中 | 按钮禁用 + 细绿色进度条 |
| 抓取失败 | 输入框下方浅红提示条，写明原因（超时 / 不是网页 / 正文为空 / 内网拒绝） |
| 预览 | 显示 4.4 的预览卡，等用户点保存 |
| 已保存 | 显示 4.5 的已保存卡 |

## 6. 必须保留的信息（简约但不删）

1. 文章标题
2. 作者（缺则「作者未知」）
3. 发布日期（缺则抓取时间）
4. 字数
5. 原文链接（可点开）
6. 正文摘要（可展开看全文）
7. 保存后的两个文件路径（Markdown + JSON）

## 7. 交互与快捷键

- 粘贴网址后，点「抓取正文」或按 **Ctrl + Enter**。
- 预览后：**保存到本地** 或 **放弃**。
- 按 **Esc** 随时重置回空状态。
- 左栏点某条记录，在浏览器打开原文。
- 本地工作区「打开 ↗」打开文件夹。

## 8. 后续预留（这次不做，但要给未来留位置）

- AI 拆解：把文章拆成 3–7 条可执行行动，人工确认。
- 行动仪表盘：一个「现在做」+ 按推荐排序的行动列表。
- 周复盘：统计完成/放弃/原因。

这些后续界面暂不设计，但整体米白简约的风格要保持一致。
