# 界面设计说明（草稿 v0.1）

> 风格：米白色、简约、不空。信息完整，不堆砌。

## 一、整体布局（一屏两栏）

```
┌─────────────────────────────────────────────────────────────┐
│ ✓ Todo Dashboard        READING → ACTION      本地存储·无账号 │  ← 顶栏
├─────────────────────────────────────────────────────────────┤
│  ┌──────────────┐                                           │
│  │  最近抓取      │       第一步 · 捕获                        │
│  │  文章1        │       把一篇博客，                          │
│  │  文章2        │       变成下一步。                          │
│  │  文章3        │                                           │
│  └──────────────┘       ┌─────────────────────────┬───────┐ │
│  ┌──────────────┐       │  https://...            │抓取正文│ │
│  │  本地工作区    │       └─────────────────────────┴───────┘ │
│  │  D:\...\data  │       支持普通博客文章…                      │
│  │  12 篇文章    │                                           │
│  └──────────────┘       ┌──────────────────────────────────┐ │
│                          │ 抓取成功 · 先确认再保存           │ │
│                          │ 文章标题                          │ │
│                          │ 作者 · 日期 · 字数                │ │
│                          │ ┌ 正文摘要… ┐                     │ │
│                          │ └──────────┘                     │ │
│                          │ 查看正文 ▾                        │ │
│                          │ [保存到本地] [放弃]  打开原文↗     │ │
│                          └──────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│ Todo Dashboard · 0.1.0          Ctrl+Enter 抓取 · Esc 重置    │  ← 底栏
└─────────────────────────────────────────────────────────────┘
```

- 左侧：辅助区（最近抓取 + 本地工作区）。
- 右侧：主操作区（标题 + 输入 + 预览/结果）。
- 顶栏、底栏固定，中间内容可滚动。

## 二、配色（米白 + 深绿点缀）

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#F6F3EA` 米白 |
| 卡片/输入底 | `#FFFDF8` 暖白 |
| 次级背景 | `#F1EDE2` 浅米灰 |
| 正文文字 | `#1D1C18` 深墨 |
| 次要文字 | `#706D63` 灰褐 |
| 分隔线 | `#E2DDD0` 浅米 |
| 主色（点缀） | `#2E6B4F` 深绿 |
| 深主色（按钮） | `#1F4B37` 墨绿 |
| 浅绿底 | `#E5EFE7` |
| 错误 | `#A8402C` + 浅红底 `#F8E6E1` |

## 三、字体与字号

- 字体：Segoe UI + Microsoft YaHei。
- 大标题 50、卡片标题 25、正文 13–15、辅助 11–12。
- 深色文字强调信息，灰色只做说明，绿色只做「可行动」的提示。

## 四、圆角与间距

- 卡片圆角 18，按钮/输入框圆角 11–12。
- 卡片内边距 22，卡片间距 18–24。
- 阴影极淡（透明度 0.10），保持干净。

## 五、每个状态的样子

1. **空状态**：左侧显示「粘贴网址，先看看抓到了什么」，右侧「还没有记录」。
2. **抓取中**：按钮变灰禁用，输入框下方一条细的绿色进度条。
3. **抓取失败**：输入框下方出现浅红提示条，写明原因（超时 / 不是网页 / 正文为空 / 内网拒绝）。
4. **预览**：显示标题、作者、日期、字数、正文摘要，展开可看全文；点「保存」才落盘。
5. **已保存**：绿色对勾 + 标题 + 两个文件路径（`.md` 和 `.json`）+「再抓一篇」。

## 六、必须保留的信息（不因简约而删）

- 标题
- 作者（无则显示「作者未知」）
- 发布日期（无则显示抓取时间）
- 字数
- 原文链接（可点开）
- 正文摘要（首屏 280 字以内，可展开全文）
- 保存后的两个文件路径

## 七、操作方式

- 粘贴网址 → 点「抓取正文」或按 `Ctrl + Enter`。
- 抓取后 → 「保存到本地」或「放弃」。
- 按 `Esc` 随时重置。
- 右侧「刷新」重读本地文件；点某条记录在浏览器打开原文。
